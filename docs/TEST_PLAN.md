# 测试与回归方案

## 自动化回归

- 配置：多根目录解析、无效根目录忽略、默认根回退。
- 目录：合法/损坏 bundle、状态映射、失败原因、帧率与同步指标、清单容量汇总。
- 安全：Capture ID 不能越出允许根，API 不接受任意文件路径或 Shell 命令。
- 作业：真实 SHA-256、固定 Pipeline、串行阶段、取消、持久化和版本化导出。
- 标识：默认语义 ID、编辑持久化、唯一性和技术 ID 不变。
- 质量：采集指标、验收报告合并、证据存在性和 `Not evaluated` 语义。
- 前端：状态文案、日期、容量、质量结果和进度格式化。
- API：健康、根目录、列表、详情、筛选、创建和取消运行。

## 浏览器验收

- 1440 x 900：导航、表格、详情栏和当前运行无重叠。
- 390 x 844：导航可横向滚动，表格保留滚动，详情转为单列。
- 空目录、API 离线、损坏 manifest、无质量结果均有明确状态。
- 页面不得将“未评估”显示成“通过”；不可用 Pipeline 必须在提交前给出原因。

## 上线处理主机前的门槛

- 用隔离的测试 Capture 验证成功、失败、取消、超时和重复执行。
- 验证 Source 文件 checksum 在运行前后不变。
- 验证半成品不可见，lineage 和工具版本可追溯。
- 运行现有 `lerobotTest` Capture 与 strict-v3 回归套件。
